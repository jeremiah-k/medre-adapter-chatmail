# Stage the provisioning journey

Present Chatmail setup as ordered stages in the README: prerequisites, profile
provisioning, invitation acceptance and chat discovery, then offline
configuration and verification. Each stage names the contributed command
verbatim and states what its observation proves and what remains unproven:
a configured profile is not relay service acceptance, an accepted chat is not
recipient delivery evidence, and offline checks never contact the profile.

State the form-less boundary: Chatmail declares no offline native setup form
because a profile requires the pinned native tooling that the contributed
commands drive. The provider contract records the provisioning evidence
levels for `init`, `accounts`, `join` and `chats`.
